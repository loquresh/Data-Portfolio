# Data-Portfolio

I am a data analyst with experience in evaluation, reporting, database design, and data modeling. I have a strong foundation in statistics and mathematics, and I've applied it to data science and analytics problems in the nonprofit sector and beyond, from predictive modeling to program evaluation. This repository showcases a selection of projects and problems I've tackled. 

## Tools

**Languages:** SQL, R, Python

**Methods:** Survey design and analysis, regression, causal inference, hypothesis testing, classification and prediction, dimensionality reduction (PCA), bootstrapping

## SF Building Permits Analysis
A SQL analysis of San Francisco's public building permits dataset, exploring how permit volume and approval speed have changed over time, and where the biggest bottlenecks are.

[View project](https://github.com/loquresh/sf-building-permits-analysis)

## Student Record Matching Using Fuzzy String Matching
A methodology for linking student survey records across multiple collection periods using fuzzy string matching, when no unique identifier is available.

[View project](https://github.com/loquresh/student-record-matching)

## Netflix Movie Rating Analysis
An analysis of movie rating patterns using matrix factorization, K-Means clustering, and PCA to predict missing ratings and explore groups of similar movies.

[View project](https://github.com/loquresh/netflix-recommender)
